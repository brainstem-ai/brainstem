## 1. packages/cli/src/tools.ts — fix bash capture

Current bash execute has bugs to fix:
- stdout/stderr handlers call `resolve(String(d))` per chunk — only the LAST chunk survives. Accumulate all chunks into a buffer instead.
- Bound retained bytes (default 256_000 per stream) while CONTINUING to drain both streams fully (child must never block on a full pipe). Record `truncated: boolean`.
- `signal ?? timeout` discards the timeout whenever a caller signal exists. Combine both: AbortSignal.any([signal, AbortSignal.timeout(ms)]) (AbortSignal.any exists in bun/node 20+). Distinguish outcomes: "ok" | "error" (nonzero exit) | "timeout" | "cancelled" (caller abort).
- Spawn errors (ENOENT etc.) → structured failure, not unhandled crash. Ensure the child is reaped (remove listeners, kill on abort).
- NONZERO EXIT IS NOT A THROW: return `{ content: [{type:"text", text: combined output}], details: { exit: code, status, durationMs, truncated } }` and let the `status: "error"` field carry failure. Keep throwing only for spawn-level failures. durationMs via performance.now.
